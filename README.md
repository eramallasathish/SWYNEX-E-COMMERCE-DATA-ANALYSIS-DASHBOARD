# E-Commerce Sales Dashboard

An interactive Power BI dashboard for exploring e-commerce order and sales performance. It brings key business metrics and several breakdowns into one view, with a month slicer to help focus the analysis.

## Overview

The dashboard summarizes order volume, sales, profit, customer count, and average orders. It also lets viewers explore sales over time, compare product categories, examine state-level sales, and review payment methods and order statuses.

## Dashboard Highlights

- KPI cards for **Total Orders**, **Sum of Sales**, **Sum of Profit**, **Total Customers**, and **Average Orders**.
- Month slicer for filtering the dashboard by month.
- Visual summaries for monthly sales, category sales, state sales, payment mode, and order status.
- Interactive Power BI visuals that support filtering and comparison.

## Key Visualizations

- **Monthly Sales Trends:** Column chart showing sales by month.
- **Sales by Category:** Donut chart comparing category contributions.
- **Sales by State:** Map displaying the geographic distribution of sales.
- **Payment Mode by Orders:** Donut chart breaking orders down by payment method.
- **Order Status:** Donut chart showing delivered, pending, returned, and cancelled orders.
